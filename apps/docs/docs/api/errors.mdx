Every error response has the same shape:

```json
{
  "error": {
    "code": "invalid_request",
    "message": "Request body too large."
  }
}
```

- `code` is a stable, machine-readable string. Match on it. New codes may be added, and none is ever renamed.
- `message` is a plain sentence for a person. Do not match on it: its wording can change.

Some errors add fields that say more: `reason`, `field` and `problem`, `max` and `maxLength`, and `ruleId`. Each route lists the codes it can return, and the [Error schema](./reference/schemas/error.schema.mdx) lists the fields.

Every authenticated route can also return `401`, `403`, `429`, `500` and `503`.

## Request size

A request body over {reference.api.requestBodyLimitBytes / 1024} KiB is refused with status `413` and code `invalid_request`. Send less per request.

## What to retry

| Status                                  | Retry?    | How                                                                                                      |
| --------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------- |
| `429 rate_limited`                      | Yes       | Wait the seconds in `Retry-After`.                                                                       |
| `503 temporarily_unavailable`           | Yes       | Wait for `Retry-After` if present, else back off: 1 s, 2 s, 4 s, with jitter, up to a few attempts.      |
| `500 internal_error`                    | Carefully | Back off as above. On a route that changes state, send an `Idempotency-Key` so a retry cannot repeat it. |
| `409 idempotency_request_in_progress`   | Yes       | Wait a moment and send the same request with the same key.                                               |
| Any other `4xx`, including other `409`s | No        | The request is wrong or the state forbids it. Change it first. Sending it again returns the same error.  |

Idempotent retries are explained in [Idempotency](./idempotency.md).
